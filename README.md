# App-BotStore

اپلیکیشن اندروید فارسی AS Team برای اتصال، مدیریت و توسعه ربات‌های شبکه‌های اجتماعی در یک پلتفرم.

## نسخه 1.2.1

این نسخه پروژه را از هویت «فقط تلگرام» خارج می‌کند و برند عمومی `App-BotStore` را مبنا قرار می‌دهد.

### امکانات فعلی

- Kotlin + Jetpack Compose + Material 3
- رابط کاربری RTL و گرافیکی
- لوگوموشن ابتدای برنامه
- ورود، ثبت‌نام و حالت «بعداً ثبت نام می‌کنم»
- دسترسی داخلی Administrator برای تست بدون محدودیت اشتراک
- داشبورد مستقل برای تلگرام، واتساپ، روبیکا و بله
- نمایش تعداد ربات‌های فعال هر پلتفرم
- نمایش ردیفی نام ربات، تاریخ خرید، تاریخ انقضا، ویرایش و تمدید
- اتصال واقعی BotFather Token تلگرام و اعتبارسنجی با Telegram `getMe`
- پلن‌های اشتراک هفتگی، یک‌ماهه، سه‌ماهه، شش‌ماهه و یک‌ساله برای هر ربات
- نمایش گرافیکی قیمت نهایی، قیمت قبل از تخفیف و درصد تخفیف
- مدیریت محصولات و دسته‌بندی‌های ربات فروشگاهی
- ویرایش اطلاعات حساب کاربری
- اعلان‌ها و بررسی بروزرسانی
- منوی همبرگری سمت راست
- بخش همگام‌سازی بین ربات‌ها با وضعیت «به‌زودی»
- مهاجرت داده ربات تلگرام از نسخه‌های قبلی

## درباره نرم‌افزار

ربات ساز شخصی شبکه های اجتماعی شما در یک پلتفرم

## معماری بروزرسانی

`applicationId` عمداً روی `ir.asteam.telegrambotstore` ثابت نگه داشته شده است. تغییر این شناسه باعث می‌شود نسخه 1.2.1 به‌جای Update به‌عنوان برنامه‌ای جداگانه نصب شود. نام برند، نام Gradle project، نام Artifactها و نام مخزن به App-BotStore تغییر می‌کنند، اما شناسه نصب ثابت می‌ماند.

## امضا

کلید خصوصی امضای Android داخل مخزن عمومی قرار نمی‌گیرد. Alias کلید برای برند جدید به `app-botstore-release` تغییر می‌کند، اما خود کلید و certificate ثابت می‌مانند تا Android بتواند نسخه جدید را روی نسخه‌های قبلی نصب کند.

## مخزن GitHub

نام هدف مخزن: `waxew/App-BotStore`

کد UpdateChecker ابتدا نام جدید و در دوره انتقال نام قدیمی را بررسی می‌کند تا هنگام Rename اختلال ایجاد نشود.

## توضیحات فارسی سورس

فایل‌های سورس و تنظیمات پروژه دارای کامنت‌های فارسی هستند که وظیفه‌ی کلاس‌ها، توابع، stateها، دستورات اصلی، تنظیمات Build و Workflow را توضیح می‌دهند.
