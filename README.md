# App-TelegramBotStore

اپ اندروید فارسی AS Team برای مدیریت ربات‌های فروشگاهی و اشتراک هر ربات.

## نسخه 1.2

- Kotlin + Jetpack Compose + Material 3
- رابط کاربری RTL، تم تیره و طراحی چندپلتفرمی
- اسپلش آغازین با لوگوموشن ربات
- ورود و ثبت‌نام + گزینه «رد کردن / بعداً ثبت نام می‌کنم»
- حالت مهمان فقط برای مشاهده؛ اتصال ربات فقط برای کاربر واردشده
- دسترسی Administrator برای تست بدون محدودیت اشتراک
- داشبورد تلگرام، واتساپ، روبیکا و بله
- نمایش «هیچ ربات فعالی ندارید» در حالت خالی
- لیست ربات‌ها شامل نام، زمان ساخت، پایان اشتراک و ویرایش
- اعتبارسنجی واقعی Telegram Bot Token با `getMe`
- پلن مستقل برای هر ربات:
  - هفتگی: 50,000 تومان
  - یک ماهه: 180,000 تومان به‌جای 200,000 تومان (10٪ تخفیف)
  - سه ماهه: 486,000 تومان به‌جای 600,000 تومان (19٪ تخفیف)
  - شش ماهه: 874,000 تومان به‌جای 1,200,000 تومان (27٪ تخفیف)
  - یک ساله: 1,584,000 تومان به‌جای 2,400,000 تومان (34٪ تخفیف)
- منوی همبرگری شامل اشتراک ربات‌ها، تنظیمات، معرفی به دوستان، درباره ما، تماس با ما و درباره نرم‌افزار
- بخش «همگام‌سازی بین ربات‌ها» به‌صورت «به‌زودی» برای نسخه‌های آینده
- لوگوی برنامه به ربات عمومی تغییر کرده تا فقط به تلگرام محدود نباشد
- مهاجرت داده ربات تلگرام نسخه قبلی به ساختار چندرباته
- شناسه ثابت `ir.asteam.telegrambotstore` برای نصب بروزرسانی روی نسخه قبلی

## وضعیت اتصال پلتفرم‌ها

در نسخه 1.2 اتصال واقعی Telegram فعال است. واتساپ، روبیکا و بله در داشبورد و معماری داده حضور دارند اما اتصال واقعی آن‌ها در نسخه‌های بعدی فعال می‌شود.

## پرداخت

رابط کاربری پلن‌ها و ثبت زمان اشتراک در نسخه 1.2 آماده است. درگاه پرداخت واقعی هنوز متصل نشده و در مرحله بک‌اند/پرداخت تکمیل می‌شود.

## Build APK

Workflow موجود در `.github/workflows/build-apk.yml` روی `main` فایل Debug و Release unsigned نسخه 1.2 را build می‌کند. APK تولیدی نهایی باید با کلید خصوصی ثابت ثبت‌شده در `SIGNING.md` امضا شود تا آپدیت روی نسخه‌های قبلی نصب شود.
