# App BotStore

اپلیکیشن اندروید فارسی AS Team برای اتصال، مدیریت و توسعه ربات‌های فروشگاهی و خدماتی در یک پنل واحد.

## نسخه فعلی: 1.3.0

### امکانات فعلی

- Kotlin + Jetpack Compose + Material 3
- رابط کاملاً RTL و تم تیره گرافیکی
- Splash / لوگوموشن
- ورود، ثبت‌نام و حالت مهمان
- دسترسی داخلی Administrator برای تست
- داشبورد پلتفرم‌های تلگرام، واتساپ، روبیکا و بله
- اتصال واقعی BotFather Token تلگرام با Telegram Bot API (`getMe`)
- مدیریت چند ربات و نمایش تاریخ ایجاد/انقضا
- پلن اشتراک مستقل برای هر ربات
- مدیریت محصولات و دسته‌بندی‌های فروشگاه
- پیش‌نمایش منوی ربات
- تنظیم اعلان‌ها و بررسی بروزرسانی از GitHub Releases
- منوی همبرگری از سمت راست
- ناوبری داخلی و Back Stack: دکمه Back ابتدا Drawer را می‌بندد و در صفحات داخلی به صفحه قبلی برمی‌گردد
- مهاجرت داده‌های نسخه‌های قبلی بدون حذف تنظیمات کاربر

## درباره نرم‌افزار

App BotStore برای ساخت، اتصال و مدیریت ربات‌های فروشگاهی و خدماتی طراحی شده است.

از داخل برنامه می‌توانید ربات، محصولات، دسته‌بندی‌ها و تنظیمات اصلی فروشگاه را مدیریت کنید.

شماره نسخه داخل خود برنامه نمایش داده می‌شود و اطلاعات فنی مانند نام پکیج در صفحه «درباره نرم‌افزار» نمایش داده نمی‌شود.

## وضعیت پلتفرم‌ها

- تلگرام: اتصال واقعی توکن فعال است.
- واتساپ، روبیکا و بله: رابط و ساختار مدیریت آماده است؛ اتصال سروری واقعی در نسخه‌های بعدی اضافه می‌شود.
- همگام‌سازی بین ربات‌ها: در Roadmap قرار دارد.

## نکته معماری مهم

این APK پنل مدیریت Android است. برای اینکه ربات‌های مشتری 24/7 حتی هنگام بسته بودن موبایل کار کنند، اجرای Bot/Webhook باید روی Backend سرور انجام شود. در Roadmap پروژه، Backend چندمستاجری و ذخیره امن توکن‌ها در اولویت قرار گرفته است.

## سازگاری بروزرسانی

شناسه نصب Android ثابت نگه داشته شده و `versionCode` در هر انتشار افزایش می‌یابد تا نسخه‌های بعدی بتوانند روی نسخه پابلیش قبلی نصب شوند و داده‌های SharedPreferences کاربر باقی بمانند.

نسخه `1.3.0` اولین نسخه پابلیش با کلید Release دائمی پروژه در نظر گرفته شده است. APKهای آزمایشی Debug قبلی ممکن است به دلیل تفاوت امضا نیاز به حذف قبل از نصب این نسخه داشته باشند؛ از این نسخه به بعد باید همین Release Key برای تمام آپدیت‌ها استفاده شود.

## کامنت‌گذاری سورس

فایل‌های اصلی Kotlin، Manifest، Gradle، Workflow و Resourceهای دست‌نویس دارای توضیحات فارسی هستند. استاندارد الزامی پروژه در `COMMENTING_GUIDE.md` ثبت شده تا فایل‌ها و قابلیت‌های جدید نیز با همان روش مستندسازی شوند.

## Build

GitHub Actions روی شاخه `main` نسخه Release را کامپایل می‌کند و دو Artifact می‌سازد:

- ورودی Release برای امضای خصوصی
- ZIP تمیز سورس پروژه

کلید خصوصی Android داخل مخزن عمومی قرار نمی‌گیرد.

## مستندات تکمیلی

- `CHANGELOG.md`: تغییرات نسخه‌ها
- `ROADMAP.md`: پیشنهاد قابلیت‌های نسخه‌های آینده
- `SIMILAR_PROJECTS.md`: پروژه‌های متن‌باز مشابه برای بررسی معماری و قابلیت‌ها
- `SIGNING.md`: اطلاعات عمومی Certificate انتشار (بدون رمز و کلید خصوصی)
