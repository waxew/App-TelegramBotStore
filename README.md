# App BotStore

اپلیکیشن اندروید فارسی AS Team برای ساخت، اتصال و مدیریت ربات‌های فروشگاهی تلگرام در یک پنل واحد.

## نسخه فعلی: 1.3.1

### تغییر اصلی نسخه 1.3.1

در نسخه‌های قبلی، وارد کردن BotFather Token فقط با `getMe` اعتبارسنجی می‌شد و خود ربات روی Backend اجرا نمی‌شد. در نسخه 1.3.1 اتصال تلگرام به Backend واقعی چندرباته منتقل شده است:

1. Android توکن را به Backend ارسال می‌کند.
2. Backend توکن را مستقیماً با Telegram Bot API اعتبارسنجی می‌کند.
3. ربات در دیتابیس ثبت می‌شود.
4. برای همان ربات `setWebhook` واقعی انجام می‌شود.
5. از آن لحظه `/start` و منوی فروشگاه از طریق Backend پاسخ داده می‌شوند؛ بسته بودن APK مانع اجرای ربات نیست.
6. محصولات و دسته‌بندی‌های ذخیره‌شده در Android به Backend همگام می‌شوند.

## Backend

Backend نسخه 1.3.1 روی Supabase Edge Functions و PostgreSQL ساخته شده است. سه Function اصلی دارد:

- `botstore-register`: اعتبارسنجی Token، ثبت Bot و `setWebhook`
- `botstore-telegram`: Webhook مشترک چندرباته و اجرای منوی فروشگاه
- `botstore-sync`: همگام‌سازی محصولات و دسته‌بندی‌های Android

Migration دیتابیس و سورس Functionها داخل پوشه `backend/supabase/` نگهداری می‌شوند تا Backend قابل بازسازی و مهاجرت باشد.

توضیحات کامل معماری در `BACKEND.md` ثبت شده است.

## محدودیت فعلی MVP

این نسخه اولین Backend عملیاتی BotStore است و هنوز کپی کامل Babba نیست. در ساختار فعلی `LocalStore` محصولات و دسته‌بندی‌ها سراسری هستند؛ بنابراین اگر چند ربات Telegram فعال باشند، فعلاً همان Catalog روی همه آن‌ها Sync می‌شود. در نسخه بعد باید Catalog به `botId` وابسته شود تا هر فروشگاه محصولات کاملاً مستقل داشته باشد.

همچنین سبد خرید، سفارش، موجودی، پرداخت، ارسال همگانی، کاربران/Block، لینک مستقیم محصول و Trial واقعی هنوز در مرحله بعدی توسعه قرار دارند.

## امنیت Backend

- هیچ `service_role` یا Secret دیتابیس داخل APK قرار نگرفته است.
- RLS روی جداول BotStore فعال است و `anon`/`authenticated` دسترسی مستقیم ندارند.
- هر ربات Telegram دارای `webhook_secret` مستقل است.
- Token در Logcat چاپ نمی‌شود.
- Endpoint Webhook فقط Update دارای Secret صحیح Telegram را پردازش می‌کند.

در MVP، Bot Token برای اجرای Telegram Bot API در جدول server-only ذخیره می‌شود. پیش از عرضه عمومی در مقیاس بالا باید Tokenها با Encryption/Vault سمت سرور محافظت شوند و ثبت/Sync نیز به حساب مالک در App BotStore متصل شود.

## وضعیت پلتفرم‌ها

- تلگرام: Backend واقعی، Webhook و Sync Catalog فعال است.
- واتساپ، روبیکا و بله: رابط Android وجود دارد؛ این نسخه BotStore هنوز Runtime فروشگاهی آن‌ها را به Backend اختصاصی جدید متصل نکرده است.
