# App-TelegramBotStore

اپ اندروید فارسی برای مدیریت فروشگاه‌ساز تلگرام.

## نسخه 1.0.0

- Kotlin + Jetpack Compose + Material 3
- رابط کاربری RTL با تم تیره و Telegram Blue
- منوی همبرگری از سمت راست
- اتصال واقعی BotFather Token و اعتبارسنجی با Telegram `getMe`
- داشبورد مدیریت ربات
- مدیریت محلی محصولات و دسته‌بندی‌ها
- پیش‌نمایش منوی فروشگاه تلگرامی
- سفارش‌ها و کاربران آماده اتصال به بک‌اند
- تنظیمات، اعلان‌ها، اشتراک‌گذاری، درباره ما، تماس با ما و درباره نرم‌افزار
- بررسی نسخه جدید از GitHub Releases
- شناسه ثابت `ir.asteam.telegrambotstore` برای نصب بروزرسانی روی نسخه قبلی

## نکته معماری

این APK کلاینت مدیریت فروشگاه است. برای اینکه ربات مشتری حتی هنگام بسته بودن گوشی 24/7 کار کند، اجرای Bot API/Webhook باید روی سرویس بک‌اند قرار گیرد. UI اندروید از ابتدا طوری جدا شده که در مرحله بعد به آن سرویس متصل شود.

## Build APK

Workflow موجود در `.github/workflows/build-apk.yml` در هر push به `main` فایل Debug APK قابل نصب می‌سازد و به‌عنوان GitHub Actions Artifact ذخیره می‌کند.
